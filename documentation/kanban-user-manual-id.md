# Panduan Pengguna Kanban Sales

## Modul yang Mendukung Kanban
- Sales Order
- Delivery Order
- Quotation

## Cara Mengakses
1. Buka halaman Sales Order, Delivery, atau Quotations dari menu Dashboard.
2. Pilih tab **Kanban** di bagian atas halaman.

## Fungsi Utama
- Pindah status dengan drag-and-drop antar kolom.
- Filter berdasarkan tanggal, customer, PIC/sales, dan status.
- Grouping card berdasarkan priority, deadline, atau customer.
- Quick action pada card: print, duplicate (jika tersedia), cancel, send email.
- Refresh data realtime dengan tombol refresh.

## Aturan Status
- Setiap modul memiliki aturan transisi status.
- Jika transisi tidak valid, sistem akan menolak perubahan.
- User tanpa izin edit hanya dapat melihat card tanpa drag-and-drop.

## Informasi yang Ditampilkan di Card
- Nomor dokumen
- Nama customer
- Total nilai
- Due date
- PIC/assigned person

## Tips Penggunaan
- Gunakan filter tanggal untuk memfokuskan pekerjaan harian.
- Gunakan grouping customer untuk follow-up per account.
- Gunakan grouping deadline untuk prioritas pekerjaan yang overdue.
